# 🌸 Iris Flower Data Visualization

A Python data visualization project that explores the famous Iris Flower Dataset using **Seaborn** and **Matplotlib**.

The project visualizes the relationships between sepal and petal measurements and compares the three Iris flower species:

- 🌹 Setosa
- 🌼 Versicolor
- 🌿 Virginica

## 📊 Visualizations

### 1. Pair Plot

The pair plot shows the relationships between:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Different colors and marker shapes are used to represent each Iris species.

### 2. Correlation Heatmap

The correlation heatmap shows how strongly the numerical features are related to each other.

## 🛠️ Technologies Used

- Python
- Matplotlib
- Seaborn
- Pandas
